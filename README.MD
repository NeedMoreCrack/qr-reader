## 注意

- **讀取圖片網址**需要網際網路（除非圖片網址是可存取的本機資源），而且仍可能受 CORS 限制。無網路時請改成圖片上傳、拖曳或貼上。
- **本機解析/產生**不需要網路，前提是 `vendor/` 已由首次設定腳本取得，且隨專案一起 clone。
- 某些瀏覽器在 `file://` 下限制剪貼簿功能；複製失敗可手動選取文字。
- `qrcode` 原先使用的版本 `1.5.4` 之 CDN build 目錄不可靠，這份使用已發布的 `1.5.1` 瀏覽器版本。
- 原始碼與授權：jsQR https://github.com/cozmo/jsQR (Apache-2.0)；node-qrcode https://github.com/soldair/node-qrcode (MIT)。若公開散布，請遵守第三方程式庫授權聲明。
